Old-fashioned Typesetting and Desktop Publishing

Old-fashioned typesetting is manually placing physical letters on a piece of paper to create printed materials for books, newspapers, posters, etc. This more of a process in the old days where technology was not invented and is a lot more time-consuming. Desktop publishing is designs used and made by a person on a computer program. Programs such as Adobe InDesign, canva, etc to create and edit documents digitally of posters, books, newspapers, etc. Users can easily change fonts, colours, images, and layouts without starting over. They both end up with the same results but old-fashioned requires alot more physical labor.

HTML and CSS

HTML and CSS are used to create webpages. HTML organizes the content using headings, paragraphs, and sections. CSS controls the colours, fonts, and layouts. HTML and CSS are mainly used for creating digital webpages.

Both methods focus on organizing text and creating readable designs, but desktop publishing is faster, easier, and more flexible than traditional typesetting.
